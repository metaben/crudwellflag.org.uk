As part of showing that we understand the land around us, we've researched existing mapping and now we create our own maps. These Crudwell area maps were created using [QGIS](https://qgis.org/), a free open source cartographic software application for PC, Mac, and Linux.

## Main watercourses
![Map 1: Main watercourses in Crudwell village](crudwell-watercourses.jpg)
Satellite imagery © Microsoft Bing Maps.

The watercourses in Crudwell village are:
1. The [Swill Brook](https://en.wikipedia.org/wiki/Swill_Brook), which rises near [Ashley, Gloucestershire](https://en.wikipedia.org/wiki/Ashley,_Gloucestershire).
2. Butts Brook, a stream that flows through a road culvert in centre of the village.
3. The Rommel Lane stream, which flows through a road culvert at the south end of the village.
4. The Village Green watercourse, which flows parallel to the A429 from the north.
